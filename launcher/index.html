这个页面独立于中转服务。即使中转已经休眠，你仍然能从这里启动它。

方式一 · 使用 GitHub 登录

无需把 GitHub 凭证交给本页面。进入你的 Codespaces 列表，打开对应环境，等待启动后回来进入聊天。

在 GitHub 中启动

方式二 · 在这里直接启动

初版使用你自己签发的 GitHub 访问令牌。它只保留在当前页面内存中，直接发送到 api.github.com，不上传给中转服务。

细粒度令牌需要该仓库的 Codespaces 读取权限，以及 Codespaces lifecycle admin 写入权限。

进入聊天

环境显示 Available 只代表云环境已运行；聊天服务和电脑连接程序也要启动。端口地址请从 Codespaces 的 Ports 面板复制。

默认闲置超时为 30 分钟；仅打开聊天网页不保证重置闲置计时。GitHub Free 每月 120 核小时，双核约 60 小时，与其他环境共享；停止后仍占用存储额度。这里不会自动续启、绕过休眠或修改付费设置。
